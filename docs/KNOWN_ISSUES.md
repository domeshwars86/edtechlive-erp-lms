# Known Issues and Open Work

- [ ] Full client/API session verification has not been completed against a persistent local database and configured email transport.
- [ ] No automated component or browser end-to-end suite exists; current CI covers typecheck, lint, production builds, backend API tests, and mobile bundling.
- [ ] Dashboard routes and role navigation still need a full authenticated browser/mobile visual review. Windows Chrome could not reach Vite/Laravel processes launched from the isolated Codex shell.
- [ ] Platform operators can suspend/reactivate organizations with an audited reason and read the resulting status-change history. Organization creation/editing, account changes, role configuration, audit coverage beyond organization status, detailed reports, subscription controls, and support tools remain unfinished.
- [ ] `public/sitemap.xml` currently uses a reserved `.example` host; replace with the approved canonical domain before launch.
- [ ] Contact enquiries are persisted and can notify a configured mailbox; a verified allowlisted operator can send replies through the configured mail transport. The enquiry record stores only response time/operator, not reply content. Local log mail transport may write message bodies to the API log; retention cleanup remains open.
- [ ] Fee records support staff-entered INR receivables and receipts, paid expense tracking, and CSV statement matching with balance checks and duplicate-statement protection. There is no payment gateway, refund workflow, idempotency key, or finance-specific role.
- [ ] Class and management meetings save scoped HTTPS links, but Google Meet provisioning, reminders, participant invites and recording workflows are not connected.
- [ ] Authentication APIs are connected, but verification/reset delivery depends on configuring an email transport.
- [ ] Sample courses and provisional plan scope/pricing are not commercial offers.
- [ ] Privacy/terms/cookie/acceptable-use/refund copy is draft material pending legal review.
- [ ] Organization invitation email uses the configured mail transport; local development logs messages, so SMTP or another delivery service must be configured for real inbox delivery. Persistent preferred-organization selection is implemented; detailed policy-based resource permissions remain.
- [ ] The latest migrations and full Laravel suite pass on disposable PostgreSQL 17 and SQLite (126 tests / 1,001 assertions). The hosted PostgreSQL 16 CI job has not yet run; production/Render database provisioning remains unverified.
- [ ] Laravel API Dockerfile and runtime-port Apache configuration are prepared but not built or deployed because Docker is unavailable in this environment; a host configuration and staging run remain necessary.
- [ ] Academic ERP is partial: sessions, classes, sections, subjects, rosters, teacher/subject/section/session assignments, invitations, direct guardian-link management, teacher-scoped attendance, timetable, student/parent attendance and result views, attendance/course-progress reports, aggregate enrollment placement, teacher workload, manual finance/expense summaries and CSV bank statement reconciliation are implemented. Remaining ERP entities and broader attendance correction workflows are still open.
- [ ] LMS includes ordered course modules, lessons, private files, enrollment, assignments/submissions/grading, scheduled single-choice/multiple-select and teacher-reviewed written-response quizzes, proportional negative marking and pass thresholds, editable course-scoped question banks with search, pagination and snapshot imports, institution exam schedules/papers/results, session/subject exam summaries, aggregate course progress and assessment outcome reports. Board-style paper sections/series, malware scanning, durable production file storage and learning notifications remain open. Laravel now sets PostgreSQL connection sessions to UTC for consistent timestamp storage/comparison; hosted PostgreSQL 16 CI remains unverified. The Expo mobile app supports written quiz answers, pending review/pass outcomes, and sign-in, workspace selection, role summaries, Admin/Management student and teacher roster overviews, today's attendance and aggregate course-progress reports, courses/lessons, student/parent profile-attendance-fee and study-material views, submissions, teacher grading/attendance, scheduled objective quizzes/results and published school exam results, notification read receipts, and scoped meeting links. Additional mobile reports/approvals, native device builds, provider integration and deployment remain unverified.
- [ ] Local registration/resend/reset now points developers to the Laravel mail log, but the local mailer still does not deliver inbox messages. Configure SMTP or another approved transport for verification and reset links.
- [ ] Mobile dependencies use security overrides for Expo SDK 56 transitive tooling; revalidate these overrides with the next Expo SDK upgrade. The latest web and mobile registry-backed audits report zero vulnerabilities.
- [ ] External Google Fonts import can fail offline; local font hosting is a possible production improvement.

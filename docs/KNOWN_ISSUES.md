# Known Issues and Open Work

- [ ] Full client/API session verification has not been completed against a persistent local database and configured email transport.
- [ ] No automated component or browser end-to-end suite exists; current CI covers typecheck, lint, production builds, backend API tests, and mobile bundling.
- [ ] Dashboard routes and role navigation still need a full authenticated browser/mobile visual review. The current local Vite preview (`127.0.0.1:4178`) and Laravel readiness endpoint (`127.0.0.1:8002/api/v1/health/ready`) both return HTTP 200; authenticated visual and end-to-end coverage remain unverified.
- [ ] Platform operators can suspend/reactivate organizations with an audited reason and read the resulting status-change history. Organization creation/editing, account changes, role configuration, audit coverage beyond organization status, detailed reports, subscription controls, and support tools remain unfinished.
- [ ] `public/sitemap.xml` currently uses a reserved `.example` host; replace with the approved canonical domain before launch.
- [ ] Contact enquiries are persisted and can notify a configured mailbox; a verified allowlisted operator can send replies through the configured mail transport. The enquiry record stores only response time/operator, not reply content. Local log mail transport may write message bodies to the API log; retention cleanup remains open.
- [ ] Fee records support staff-entered INR receivables and receipts, paid expense tracking, and CSV statement matching with balance checks and duplicate-statement protection. There is no payment gateway, refund workflow, idempotency key, or finance-specific role.
- [ ] Class and management meetings save scoped HTTPS links, but Google Meet provisioning, reminders, participant invites and recording workflows are not connected.
- [ ] Local registration and resend-verification responses expose a short-lived signed link in the auth screen; real verification/reset inbox delivery still depends on configuring an email transport.
- [ ] Sample courses and provisional plan scope/pricing are not commercial offers.
- [ ] Privacy/terms/cookie/acceptable-use/refund copy is draft material pending legal review.
- [ ] Organization invitation email uses the configured mail transport; local development logs messages, so SMTP or another delivery service must be configured for real inbox delivery. Persistent preferred-organization selection is implemented; detailed policy-based resource permissions remain.

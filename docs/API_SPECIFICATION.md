# API Specification (Proposed)

**Status:** Health, authentication, password recovery, email verification, organization invitations, current-user, organization reads, allowlisted platform overview, academic masters, institution exams/results, people rosters, direct guardian link management, teaching assignments, attendance, timetable, family access, enrollment, teacher workload, finance, statement reconciliation, assessment and course progress reports, role-scoped dashboard summaries and learning activity, courses, modules, lessons, enrollments, private course assets, assignments, submissions, grading, quizzes, attempts, fees, meetings, in-app notifications, and public contact enquiries are implemented. Other routes remain proposals.

Base path: `/api/v1`. JSON requests/responses. Authenticated endpoints return consistent validation and authorization errors; lists are paginated. Organization context is explicit in authorized routes and verified against the authenticated user's active membership. Never trust a client-provided organization ID without policy enforcement.

| Area | Proposed routes |
|---|---|
| Health | `GET /health` |
| Identity | `POST /auth/register`, `POST /auth/login`, `POST /auth/logout`, `POST /auth/forgot-password`, `POST /auth/reset-password`, `GET /me` |
| Organizations | `GET/POST /organizations`, `GET/PATCH /organizations/{organization}`, `POST /organizations/{organization}/switch`, `POST /organizations/{organization}/invitations` |
| Academic masters | `GET/POST /organizations/{organization}/academic-sessions`, `/classes`, `/sections`, `/subjects`, `/batches` |
| People | `GET/POST /organizations/{organization}/students`, `/teachers`, `/memberships`; relationship-specific guardian routes |
| Learning | `GET/POST /organizations/{organization}/courses`, `/courses/{course}/modules`, `/lessons`, `/enrollments`, `/assets` |
| Attendance/schedule | `GET/POST /organizations/{organization}/attendance`, `/schedules` |
| Assessment | `GET/POST /organizations/{organization}/assignments`, `/submissions`, `/exams`, `/attempts`, `/results` |
| Meetings | `GET/POST /organizations/{organization}/meetings`; provider creation is optional, manual URL entry supported |
| Reports/notifications | `GET /organizations/{organization}/reports/*`, `GET/PATCH /notifications`, `POST /notifications/{id}/read` |
| Enquiries | `POST /enquiries` with throttling, validation and anti-abuse controls |
| Finance | `GET/POST /organizations/{organization}/invoices`, `POST /payments/intents`, signed provider webhook endpoint |
| AI | `POST /ai/explanations`, `/ai/question-drafts` with authorization, quotas and moderation |

## Implemented routes

| Method and path | Access | Behavior |
|---|---|---|
| `GET /api/v1/health` | Public | Returns service health and API version; does not assert database connectivity. |
| `GET /api/v1/health/ready` | Public infrastructure probe | Executes a database readiness query; returns 200 when ready or a generic 503 without exposing connection details. `/api/v1/health` remains a liveness check that does not require the database. |
| `GET /api/v1/organizations/{organization}/courses/{course}/progress` | Verified student with active enrollment, course teacher, admin, management, or independent educator | Students receive their own published lesson completion timestamps and summary. Course teachers/managers receive active enrolled learner completion counts and percentages; teacher access is restricted to their own course. |
| `GET/POST/PATCH /api/v1/organizations/{organization}/courses/{course}/modules` | Enrolled student may list visible modules; course teacher or organization manager may list and author | Creates and edits ordered modules within a course. Student listings include only modules containing published lessons in a published course with active enrollment. Lessons may be associated only with a module belonging to the same course and organization. |
| `GET /api/v1/organizations/{organization}/reports/course-progress` | Admin, management, independent educator, or teacher with active organization membership | Summarizes published-course lesson counts, active enrollment totals, average completion, and fully completed learners. Teachers only see courses they own; student names are omitted. |
| `GET /api/v1/organizations/{organization}/reports/enrollment` | Admin, management, or independent educator | Returns aggregate active learner placement by session/section, unassigned learner count, and enrollments in published courses. It is tenant-scoped and excludes personal identifiers. |
| `GET /api/v1/organizations/{organization}/reports/workload` | Admin, management, or independent educator | Returns active teacher section assignments, per-teacher distinct active learner reach, and active weekly timetable slot counts/hours for sessions active on the organization's local date. Teacher and learner roles cannot read organization-wide totals. |
| `GET /api/v1/organizations/{organization}/reports/finance?from={date}&to={date}` | Admin, management, or independent educator | Returns organization-wide INR fee record counts, issued/received/outstanding/overdue totals, all-time expenses and net cash flow, plus date-filtered receipt/outflow counts and totals (default: last 30 days, maximum: 366 days). This report aggregates staff-entered records; bank statement matching is a separate manual workflow and does not connect to a payment provider. |
| `GET /api/v1/organizations/{organization}/exams` | Admin, management, independent educator, or teacher | Lists up to 100 tenant exams with papers. Teachers see exams and papers only for matching teaching assignments. |
| `POST /api/v1/organizations/{organization}/exams` | Admin, management, or independent educator | Creates a draft examination inside an active academic session date window. |
| `POST /api/v1/organizations/{organization}/exams/{exam}/papers` | Admin, management, or independent educator | Schedules a unique section/subject paper with exam date and maximum marks. |
| `GET /api/v1/organizations/{organization}/exam-papers/{paper}/results` | Admin, management, independent educator, or assigned teacher | Lists the active student roster and saved marks for the paper. Teachers are limited to their assigned session, section and subject. |
| `PUT /api/v1/organizations/{organization}/exam-papers/{paper}/results` | Admin, management, independent educator, or assigned teacher | Saves grades, absences or excused outcomes for active students; score caps, roster placement and published-result lock are enforced. |
| `POST /api/v1/organizations/{organization}/exams/{exam}/publish` | Admin, management, or independent educator | Publishes only after each active roster student has a result or absence for every paper. Published results become read-only. |
| `GET /api/v1/organizations/{organization}/reports/exams?session_id={id}` | Admin, management, independent educator, or teacher | Summarizes published exam results by exam, section and subject with graded/absent/excused counts and average marks; teachers see only papers in their exact assigned session/section/subject scope. Student identities are omitted. |
| `GET /api/v1/organizations/{organization}/my/student/results`, `GET .../my/children/{student}/results` | Student, or parent with an explicit child link | Includes only published institution exam results for the authenticated student or linked active child, alongside quiz and assignment results. |
| `GET /api/v1/organizations/{organization}/bank-statements` | Admin, management, or independent educator | Lists up to 30 tenant-owned imported statement batches and their matched/unmatched transaction lines. |
| `POST /api/v1/organizations/{organization}/bank-statements` | Admin, management, or independent educator | Imports 1–500 CSV-decoded lines with account label, period, opening/closing balances, date, description, credit/debit, amount and optional reference. The balance equation must reconcile; duplicate statement contents are rejected using a tenant-scoped fingerprint; no bank credentials or raw uploaded file are stored. |
| `GET /api/v1/organizations/{organization}/bank-statement-lines/{line}/candidates` | Admin, management, or independent educator | Finds up to 50 unmatched same-tenant fee receipts or paid expenses with exact amount and dates within seven days, according to line direction. |
| `POST /api/v1/organizations/{organization}/bank-statement-lines/{line}/match` | Admin, management, or independent educator | Links the line to one same-tenant fee receipt or expense. Direction, exact amount, seven-day date window and one-to-one matching are enforced. |
| `DELETE /api/v1/organizations/{organization}/bank-statement-lines/{line}/match` | Admin, management, or independent educator | Reverses a match while retaining the imported statement line. |
| `GET/POST /api/v1/organizations/{organization}/expenses` | Admin, management, or independent educator | Lists tenant-scoped recorded expenses and records a paid operating expense with category, amount, organization-local date, method and optional reference/notes. Future dates are rejected. |
| `GET/POST /api/v1/organizations/{organization}/announcements` | Admin, management, or independent educator | Lists recent organization notices or immediately sends a bounded title/body to all active members or a role audience through recipient-owned in-app notifications. |
| `GET /api/v1/organizations/{organization}/reports/assessments` | Admin, management, independent educator, or teacher | Summarizes published quizzes and assignments, attempt/submission/review counts, learner participation, and weighted score averages. Teachers are limited to their published courses. Student identity is omitted. |
| `PUT /api/v1/organizations/{organization}/courses/{course}/lessons/{lesson}/progress` | Same as above | Sets or clears completion for a published lesson in the enrolled course; each student can only change their own progress. |
| `GET /api/v1/organizations/{organization}/fees` | Verified admin, management, independent educator, linked student, or linked parent | Returns organization fees to authorized staff; students see only their linked profile and parents only explicitly linked active children. Supports staff `student_id` and status filters. |
| `POST /api/v1/organizations/{organization}/fees` | Admin, management, or independent educator | Creates a manual INR receivable for one active organization student, with optional due date/session. Does not charge money. |
| `POST /api/v1/organizations/{organization}/fees/{fee}/payments` | Admin, management, or independent educator | Records money already received by staff with method/reference and receiver audit fields. Partial receipts are supported; overpayment is rejected transactionally. This is not a payment gateway. |
| `GET /api/v1/organizations/{organization}/meetings` | Verified organization managers, assigned teachers, enrolled students, or linked parents | Lists management meetings for managers; class meetings are limited to the caller's assigned teaching sections/courses, enrolled student sections/courses, or explicitly linked children's sections/courses. |
| `GET /api/v1/organizations/{organization}/notifications` | Verified active organization member | Lists only notifications addressed to the caller and tagged for the selected organization; unread entries sort first and `per_page` is bounded to 1–100. |
| `POST /api/v1/organizations/{organization}/notifications/{notification}/read` | Verified active organization member and notification recipient | Marks one of the caller's notifications for that organization as read; other users' and organizations' IDs return not found. |
| `GET /api/v1/organizations/{organization}/dashboard/summary` | Admin, management, independent educator, active assigned teacher, linked student, or linked parent | Admin/management receive active roster counts, timetable slots for today, and today's attendance. Independent educators receive published course, unique learner, ungraded submission, and upcoming live class counts. Teachers receive their active assigned class/learner counts, ungraded submissions for their own published courses, and weekly assigned timetable slots. Students receive their own active course count, lessons completed over the last seven local calendar days, unsubmitted published assignment count, and 30-day attendance. Parents receive linked active child count, child-only pending assignments and attendance, and upcoming meetings only for linked sections/courses. Date windows use the organization timezone; no attendance marks returns a null rate. |
| `GET /api/v1/organizations/{organization}/dashboard/activity` | Admin, management, independent educator, linked teacher, student, or parent | Returns seven organization-local day totals of published lesson completions and assignment submissions. Teachers are limited to their published courses; learners only see their own activity; parents see activity for explicitly linked active children. It returns aggregate counts without learner identifiers. |
| `POST /api/v1/organizations/{organization}/meetings` | Admin, management, independent educator; teachers with a matching teaching assignment | Schedules a one-time management or class meeting with an HTTPS provider URL. Start/end times, organization-owned course/section/session, and overlapping class meetings are validated. Provider room creation is not connected. |
| `PATCH /api/v1/organizations/{organization}/meetings/{meeting}` | Admin, management, independent educator, or the teacher who created the class meeting | Cancels a meeting without deleting its audit record. Students and parents are read-only. |
| `POST /api/v1/enquiries` | Public, limited to 6 requests per minute per client | Validates contact details and explicit consent, silently drops honeypot submissions, and persists accepted enquiries. Sends a raw notification only when `ENQUIRY_RECIPIENT` and a real mail transport are configured; response reports whether notification was sent. |
| `GET /api/v1/enquiries?status={status}&q={search}` | Authenticated, verified user whose email is explicitly listed in `ENQUIRY_ADMIN_EMAILS` | Returns paginated contact records, optionally filtered by status and search text; this is a platform-wide operator capability and is not granted by organization membership. |
| `GET /api/v1/platform/overview` | Verified user whose email is explicitly listed in `PLATFORM_ADMIN_EMAILS` | Returns aggregate organization/user/educator/enquiry counts and recently created organization metadata; tenant membership does not grant platform access. |
| `GET /api/v1/platform/organizations?q={search}&status={status}` | Same verified platform operator allowlist | Returns paginated organization metadata with active membership/student/teacher totals; read-only, searchable by name or slug, and filterable by active/suspended status. |
| `PATCH /api/v1/enquiries/{id}` | Same allowlisted platform operator | Sets status to `new`, `in_progress`, `resolved`, or `archived`; records reviewer and review timestamp. Replies open in the operator mail client and are not sent by the platform. |
| `POST /api/v1/auth/register` | Public, throttled | Validates name, email, 12+ character letter-and-number password, organization name/type; creates user, organization, and initial active membership in one transaction; sends verification. Duplicate-email response is intentionally generic. |
| `POST /api/v1/auth/login` | Public, throttled | Requires verified account and valid credentials. Without `device_name`, creates a first-party browser session. With `device_name`, issues a 30-day Sanctum bearer token. |
| `POST /api/v1/auth/logout` | Sanctum authenticated | Deletes the current bearer token or invalidates the browser session. |
| `POST /api/v1/auth/email/verification-notification` | Public, throttled | Sends a verification message when an unverified account exists; response does not reveal account existence. |
| `GET /api/v1/auth/verify-email/{id}/{hash}` | Signed, throttled | Validates the expiring signed URL and marks the matching user email as verified. |
| `POST /api/v1/auth/forgot-password` | Public, throttled | Sends password reset instructions when an account exists; response is generic. Link is built for `FRONTEND_URL/reset-password`. |
| `POST /api/v1/auth/reset-password` | Public, throttled | Accepts email, reset token, and confirmed password; consumes the reset token and revokes existing API tokens. |
| `GET /api/v1/me` | Sanctum authenticated | Returns current user's ID, name, email, verification timestamp and whether their email is allowlisted for platform operations; omits credentials. |
| `GET /api/v1/organizations` | Sanctum authenticated and verified | Returns paginated active organization memberships for the current user only, including role and basic organization details, plus `preferred_organization_id` when that organization is still active and accessible. `per_page` is bounded to 1–100. |
| `PATCH /api/v1/me/organization` | Sanctum authenticated and verified | Saves the user's preferred organization only after checking that the user has an active membership and the organization is active; returns the selected membership. |
| `GET /api/v1/organizations/{organization}` | Sanctum authenticated and verified | Returns organization details only to an active member; other users receive 404. |
| `PATCH /api/v1/organizations/{organization}/settings` | Verified admin or independent educator in the active organization | Updates the organization name and/or IANA timezone. Empty updates and invalid timezones are rejected; management and other roles are denied. |
| `GET /api/v1/organizations/{organization}/invitations` | Admin, management, or independent educator in an active verified membership | Lists tenant invitations with pending, accepted, or expired state. |
| `POST /api/v1/organizations/{organization}/invitations` | Same roles; management invitations are admin-only | Sends a seven-day invitation to a permitted role. Student invites require an active matching student roster email; parent invites require 1–20 active tenant student IDs. Raw tokens are never returned by the API; invitations can be revoked before acceptance. |
| `GET /api/v1/organizations/{organization}/parent-accounts` | Admin, management, or independent educator | Lists active, verified parent accounts in this organization for linking to student records. |
| `GET/POST /api/v1/organizations/{organization}/students/{student}/guardians` | Admin, management, or independent educator | Lists a student's explicit guardian links or links an active, verified parent membership. Supports relationship type and primary-contact status; selecting a new primary clears the previous primary link. |
| `DELETE /api/v1/organizations/{organization}/students/{student}/guardians/{guardian}` | Admin, management, or independent educator | Removes only the selected organization/student/guardian link. Guardian users must be active parent members of the same organization before linking. |
| `DELETE /api/v1/organizations/{organization}/invitations/{record}` | Same roles | Revokes a pending invitation. Accepted invitations cannot be revoked through this route. |
| `GET /api/v1/auth/invitations/{token}` | Public, throttled | Returns invitation email, role, organization name, and expiry for a valid one-time token. |
| `POST /api/v1/auth/invitations/register` | Public, throttled | New invitees create an account and accept; existing invitees confirm with their account password. The invitation proves email access and activates a membership. Teacher and student acceptance link the matching roster profile; parent acceptance links only the student profiles selected on the invitation. |
| `POST /api/v1/organizations/{organization}/invitations/{token}/accept` | Authenticated, verified invitee whose email matches the invitation | Accepts an invitation for an existing signed-in account. |
| `GET/POST /api/v1/organizations/{organization}/academic-sessions` | Verified active organization member; writes by admin, management, or independent educator | Lists or creates tenant-scoped sessions. Dates must be ordered; session names are unique per organization; current-session switching is transactional. |
| `PATCH /api/v1/organizations/{organization}/academic-sessions/{record}` | Same as above | Updates a tenant-scoped session; inactive sessions cannot be current. |
| `GET/POST /api/v1/organizations/{organization}/classes` | Verified active organization member; writes by admin, management, or independent educator | Lists or creates organization classes with optional unique code and sort order. |
| `PATCH /api/v1/organizations/{organization}/classes/{record}` | Same as above | Updates name, code, sort order, or active state. |
| `GET/POST /api/v1/organizations/{organization}/classes/{class}/sections` | Verified active organization member; writes by admin, management, or independent educator | Lists or creates class sections; an academic session reference must belong to the same organization. |
| `PATCH /api/v1/organizations/{organization}/sections/{record}` | Same as above | Updates section name, session, capacity, or active state. |
| `GET/POST /api/v1/organizations/{organization}/subjects` | Verified active organization member; writes by admin, management, or independent educator | Lists or creates subjects with optional unique code and description. |
| `PATCH /api/v1/organizations/{organization}/subjects/{record}` | Same as above | Updates subject details or active state. |
| `GET/POST /api/v1/organizations/{organization}/students` | Admin, management, or independent educator in an active verified membership | Lists a paginated roster with search/status filters or creates a student profile. Enrollment class, section, and session references must be organization-owned. |
| `PATCH /api/v1/organizations/{organization}/students/{record}` | Same roles | Updates profile, placement, enrollment date, or lifecycle status. Student records are not login accounts. |
| `GET/POST /api/v1/organizations/{organization}/teachers` | Same roles | Lists a paginated staff roster with search/status filters or creates a teacher profile. |
| `PATCH /api/v1/organizations/{organization}/teachers/{record}` | Same roles | Updates teacher contact/specialization details or status. Staff login invitations are not included yet. |
| `GET /api/v1/organizations/{organization}/teaching-assignments` | Admin, management, or independent educator; teachers see their own linked profile assignments | Lists teacher/subject/section assignments, optionally filtered by session and teacher. |
| `POST /api/v1/organizations/{organization}/teaching-assignments` | Same roles | Assigns an active teacher to a subject and section in a matching active academic session; repeated requests are idempotent. |
| `DELETE /api/v1/organizations/{organization}/teaching-assignments/{record}` | Same roles | Removes a tenant-owned teaching assignment. A teacher cannot be scheduled for the matching section/subject/session without this assignment. |
| `GET /api/v1/organizations/{organization}/attendance` | Admin, management, independent educator, or linked teacher assigned to the section/session | Returns a paginated section roster with saved marks for a date inside the section's academic session. |
| `PUT /api/v1/organizations/{organization}/attendance` | Same roles | Batch upserts present/absent/late/excused marks and optional notes. Students must be active and enrolled in that section/session; teachers can mark only assigned sections. |
| `GET /api/v1/organizations/{organization}/my/student` | Verified active student member | Returns the active student roster profile linked to the signed-in account. |
| `GET /api/v1/organizations/{organization}/my/student/attendance` | Verified active student member | Returns paginated attendance only for the signed-in student's linked roster profile; optional `from` and `to` date filters are supported. |
| `GET /api/v1/organizations/{organization}/my/children` | Verified active parent member | Returns only active student profiles explicitly linked to the signed-in parent. |
| `GET /api/v1/organizations/{organization}/my/children/{student}/attendance` | Verified parent linked to the requested student | Returns paginated attendance only for the explicitly linked active child; other students return 404. |
| `GET /api/v1/organizations/{organization}/my/student/results` | Verified active student member | Returns the student's last 100 submitted quiz scores and graded assignment scores/feedback from published courses; answers and submission text are excluded. |
| `GET /api/v1/organizations/{organization}/my/children/{student}/results` | Verified parent linked to the requested student | Returns the linked active child's last 100 submitted quiz outcomes and graded assignment scores/feedback; unlinked children return 404 and answer/submission content is excluded. |
| `GET /api/v1/organizations/{organization}/my/student/progress` | Verified active student member | Returns published-course lesson completion for the signed-in student, limited to active enrollments. |
| `GET /api/v1/organizations/{organization}/my/children/{student}/progress` | Verified parent linked to the requested student | Returns published-course lesson completion for the explicitly linked active child; unlinked children return 404. |
| `GET /api/v1/organizations/{organization}/my/student/homework` | Verified active student member | Lists published assignments in the student's active published-course enrollments with due, submission and grade state; answer text is omitted. |
| `GET /api/v1/organizations/{organization}/my/children/{student}/homework` | Verified parent linked to the requested student | Lists that linked active child's published assignments with due, submission, grade and feedback state; unlinked children return 404 and answer text is omitted. |
| `GET /api/v1/organizations/{organization}/reports/attendance?from={date}&to={date}` | Verified admin, management, or independent educator member | Returns date-filtered attendance totals and class/section breakdowns. Late marks count toward attendance rate. Optional `session_id` is tenant validated; end date must not precede start date. |
| `GET /api/v1/organizations/{organization}/courses` | Verified manager, linked teacher, or linked student | Managers see organization courses, teachers see courses linked to their teacher profile, and students see only published courses with an active enrollment. |
| `POST /api/v1/organizations/{organization}/courses` | Verified manager or linked teacher | Creates a draft course. Optional subject/teacher references must belong to the organization; teacher-created courses are linked to their own roster profile. |
| `PATCH /api/v1/organizations/{organization}/courses/{record}` | Verified manager or course's linked teacher | Updates course details/status. Publishing requires a published lesson. |
| `GET/POST /api/v1/organizations/{organization}/courses/{course}/lessons` | Course manager/editor; enrolled student may read published lessons | Adds lesson content or an HTTPS resource link; publishing requires at least one content body or HTTPS resource URL. Students cannot read drafts or courses without enrollment. |
| `POST /api/v1/organizations/{organization}/courses/{course}/enrollments` | Verified manager | Enrolls 1–200 active student roster profiles into a published course; repeated enrollment reactivates the same course/student record. |
| `GET/POST /api/v1/organizations/{organization}/courses/{course}/assignments` | Course manager/editor; enrolled student may list published assignments | Creates draft/published assignments or lists available work. Students see only published assignments for an active course enrollment; each item includes only their own submission/grade. |
| `PATCH /api/v1/organizations/{organization}/assignments/{record}` | Course manager or linked teacher | Updates assignment prompt, due date, maximum score, or publication status. |
| `POST /api/v1/organizations/{organization}/assignments/{assignment}/submissions` | Linked student actively enrolled in the published course | Creates or updates the student's text response until it has been graded. Each assignment/student pair has one submission record. Late work is accepted and retains its submission timestamp. |
| `GET /api/v1/organizations/{organization}/assignments/{assignment}/submissions` | Course manager or linked teacher | Lists submissions for one tenant-owned assignment, including student roster name and admission number. |
| `PATCH /api/v1/organizations/{organization}/submissions/{submission}/grade` | Course manager or linked teacher | Stores a numeric score no higher than the assignment maximum and optional feedback; records grader and grading time. |
| `GET/POST /api/v1/organizations/{organization}/courses/{course}/quizzes` | Course manager/editor; enrolled student may list published quizzes | Creates draft quizzes or lists authorized quizzes. Student responses omit correct answer indexes and include only their own latest attempt/result. |
| `PATCH /api/v1/organizations/{organization}/quizzes/{quiz}` | Course manager or linked teacher | Updates quiz settings or publishes it after at least one question has been added. Question/settings edits are locked after publication. |
| `POST /api/v1/organizations/{organization}/quizzes/{quiz}/questions` | Course manager or linked teacher on a draft quiz | Adds a 2–6 option MCQ with a server-stored correct answer, points, and display order. |
| `POST /api/v1/organizations/{organization}/quizzes/{quiz}/attempts` | Linked student actively enrolled in the published course | Starts a timed or untimed attempt, subject to configured attempt limit; returns prompts and choices without the answer key. |
| `PATCH /api/v1/organizations/{organization}/quizzes/{quiz}/attempts/{attempt}` | Student who owns the active attempt | Submits selected question options; score and maximum are calculated server-side. Attempts past their time limit are closed with a zero score. |
| `GET /api/v1/organizations/{organization}/quizzes/{quiz}/attempts` | Course manager/editor or enrolled student | Returns submitted attempts; students see only their own result, teachers/managers see roster identity and scores. |
| `GET/POST /api/v1/organizations/{organization}/courses/{course}/assets` | Course manager/editor; enrolled student may list published materials | Lists authorized metadata or uploads an allow-listed PDF, Office document, or image (maximum 20 MB) into private storage. Uploads start unpublished. |
| `GET /api/v1/organizations/{organization}/documents` | Active organization member with an allowed role | Returns paginated course files; managers see organization files, teachers see their own courses, students see published files only from actively enrolled courses, and parents see published files only for actively enrolled children explicitly linked to them. |
| `PATCH /api/v1/organizations/{organization}/assets/{record}` | Course manager or linked teacher | Publishes/unpublishes a course asset; publishing requires a published course. |
| `GET /api/v1/organizations/{organization}/assets/{record}/download` | Course manager/editor, enrolled student, or linked parent for a published asset | Streams a private attachment after checking active organization membership, course ownership/enrollment, and asset publication. Parents must have an explicit guardian link to an active student actively enrolled in the published course. The API does not reveal storage keys. |
| `GET /api/v1/organizations/{organization}/timetable` | Admin, management, independent educator, or linked teacher | Lists paginated weekly entries with optional session, section, and weekday filters; teachers only see their own entries. |
| `POST/PATCH /api/v1/organizations/{organization}/timetable` | Same roles | Creates or updates a section/subject slot, optional assigned teacher/room/HTTPS meeting link, and rejects active section, teacher, or room conflicts. |

Browser clients use Sanctum's stateful session flow with `/sanctum/csrf-cookie`; configure `SANCTUM_STATEFUL_DOMAINS`, `CORS_ALLOWED_ORIGINS`, and `FRONTEND_URL` for each environment. Native clients request a token by including `device_name` on login. Email delivery must be configured for verification and reset links to reach users.

Document schemas, error codes, scopes and OpenAPI contracts alongside implementation; do not advertise proposed endpoints as available.

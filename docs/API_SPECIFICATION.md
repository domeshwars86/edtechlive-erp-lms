# API Specification (Proposed)

**Status:** Health, authentication, password recovery, email verification, organization invitations, current-user, organization reads, allowlisted platform overview, academic masters, institution exams/results, people rosters, direct guardian link management, teaching assignments, attendance, timetable, family access, enrollment, teacher workload, finance, statement reconciliation, assessment and course progress reports, role-scoped dashboard summaries and learning activity, courses, modules, lessons, enrollments, private course assets, assignments, submissions, grading, course-scoped question banks, quizzes, attempts, fees, meetings and manually uploaded meeting recordings with short-lived signed download links, in-app notifications, opt-in queued workspace email with delivery status, and contact enquiry intake/replies are implemented. Provider delivery remains disabled until configured. Other routes remain proposals.

Base path: `/api/v1`. JSON requests/responses. Authenticated endpoints return consistent validation and authorization errors; lists are paginated. Organization context is explicit in authorized routes and verified against the authenticated user's active membership. Never trust a client-provided organization ID without policy enforcement.

| Area | Proposed routes |
|---|---|
| Health | `GET /health` |
| Identity | `POST /auth/register`, `POST /auth/login`, `POST /auth/logout`, `POST /auth/forgot-password`, `POST /auth/reset-password`, `GET /me` |
| Organizations | `GET/POST /organizations`, `GET/PATCH /organizations/{organization}`, `POST /organizations/{organization}/switch`, `POST /organizations/{organization}/invitations` |
| Academic masters | `GET/POST /organizations/{organization}/academic-sessions`, `/classes`, `/sections`, `/subjects`, `/batches`, `/branches` |
| People | `GET/POST /organizations/{organization}/students`, `/teachers`, `/memberships`; relationship-specific guardian routes |
| Learning | `GET/POST /organizations/{organization}/courses`, `/courses/{course}/modules`, `/lessons`, `/enrollments`, `/assets` |
| Attendance/schedule | `GET/POST /organizations/{organization}/attendance`, `/schedules` |
| Assessment | `GET/POST /organizations/{organization}/assignments`, `/submissions`, `/exams`, `/attempts`, `/results` |
| Meetings | `GET/POST /organizations/{organization}/meetings`; scoped schedule, upload/link private recordings, publish/withdraw and authenticated download |
| Reports/notifications | `GET /organizations/{organization}/reports/*`, `GET/PATCH /notifications`, `POST /notifications/{id}/read`, `GET /organizations/{organization}/email-deliveries`, `GET/PATCH /me/notification-preferences` |
| Enquiries | `POST /enquiries` with throttling, validation and anti-abuse controls |
| Finance | `GET/POST /organizations/{organization}/invoices`, `POST /payments/intents`, signed provider webhook endpoint |
| AI | `POST /ai/explanations`, `/ai/question-drafts` with authorization, quotas and moderation |

## Implemented routes

| Method and path | Access | Behavior |
|---|---|---|
| `GET /api/v1/health` | Public | Returns service health and API version; does not assert database connectivity. |
| `GET /api/v1/health/ready` | Public infrastructure probe | Executes a database readiness query; returns 200 when ready or a generic 503 without exposing connection details. `/api/v1/health` remains a liveness check that does not require the database. |
| `GET /api/v1/public/courses?q={term}&level={level}&subject={subject}&page={n}&per_page={n}` | Public, throttled | Returns only explicitly public, published courses with at least one published lesson from active organizations. Supports bounded pagination, text search, level/subject filters and distinct filter options. The response contains safe course/organization display fields and published lesson counts; it omits IDs, teacher account data, lesson bodies/assets and enrollment data. |
| `GET /api/v1/public/organizations/{organizationSlug}/courses/{courseSlug}` | Public, throttled | Returns a single eligible course with safe organization/subject/level metadata and ordered published lesson titles only. The organization and course must both still be eligible for public listing. |
| `GET /api/v1/organizations/{organization}/batches` | Active organization member | Lists tenant batches with paginated search by name/code and optional class, session and active-status filters. |
| `POST /api/v1/organizations/{organization}/batches` | Admin, management, or independent educator | Creates a batch tied to an organization-owned academic session and class; an optional section must match both. |
| `PATCH /api/v1/organizations/{organization}/batches/{record}` | Admin, management, or independent educator | Updates batch details or activates/deactivates it; tenant ownership and academic placement are revalidated. |
| `GET /api/v1/organizations/{organization}/branches` | Active organization member | Lists organization-owned branches with paginated case-insensitive name/code search and active-status filtering. |
| `POST /api/v1/organizations/{organization}/branches` | Admin, management, or independent educator | Creates a branch with a unique tenant name/code and optional address/contact details. |
| `PATCH /api/v1/organizations/{organization}/branches/{record}` | Admin, management, or independent educator | Edits branch details or activates/deactivates it; records in other organizations are not addressable. |
| `GET /api/v1/organizations/{organization}/classes` | Active organization member | Lists paginated classes with optional `branch` details for branch-aware academic setup. |
| `GET /api/v1/organizations/{organization}/fee-categories` | Active organization member | Lists tenant fee categories with paginated name/code search and active-status filters. |
| `POST /api/v1/organizations/{organization}/fee-categories` | Admin, management, or independent educator | Creates a fee category with a tenant-unique name and optional code/description. |
| `PATCH /api/v1/organizations/{organization}/fee-categories/{record}` | Admin, management, or independent educator | Edits category metadata or activates/deactivates it; existing fee records retain their category association. |
| `GET /api/v1/organizations/{organization}/memberships` | Member with effective `organization.memberships.read` | Lists active/suspended member name, email, role, status and effective/explicit permissions with search and role/status filters; also returns the permission catalog and membership/permission management flags. Admin and independent educator defaults include all catalog capabilities; Management defaults to read. Pending invitations remain in the invitation workflow. |
| `PATCH /api/v1/organizations/{organization}/memberships/{membership}` | Member with effective `organization.memberships.manage`; permission overrides require Admin or Independent Educator | Changes an eligible member role, status, and/or full explicit permission-override list. Granting manage or audit automatically grants member-list read access. Delegated managers cannot touch privileged targets or assign a role above the target's current privilege rank. Permission grants cannot target self, suspended or privileged memberships. Cross-tenant records, self-changes, invalid keys and a change that removes the last active privileged manager are rejected; successful changes are audited. This capability system currently governs membership workflows only. |
| `GET /api/v1/organizations/{organization}/membership-access-audit` | Member with effective `organization.memberships.audit` | Lists recent role, status and permission changes with actor, subject, event type, prior/current values and timestamp. |
| `GET /api/v1/organizations/{organization}/courses/{course}/progress` | Verified student with active enrollment, course teacher, admin, management, or independent educator | Students receive their own published lesson completion timestamps and summary. Course teachers/managers receive active enrolled learner completion counts and percentages; teacher access is restricted to their own course. |
| `PATCH /api/v1/organizations/{organization}/courses/{course}` | Authorized course editor | Accepts `is_public_listing` only for an already published course; unpublishing a course clears its public listing. Course editor role and tenant checks continue to apply. |
| `GET/POST/PATCH /api/v1/organizations/{organization}/courses/{course}/modules` | Enrolled student may list visible modules; course teacher or organization manager may list and author | Creates and edits ordered modules within a course. Student listings include only modules containing published lessons in a published course with active enrollment. Lessons may be associated only with a module belonging to the same course and organization. |
| `GET /api/v1/organizations/{organization}/reports/course-progress` | Admin, management, independent educator, or teacher with active organization membership | Summarizes published-course lesson counts, active enrollment totals, average completion, and fully completed learners. Teachers only see courses they own; student names are omitted. |
| `GET /api/v1/organizations/{organization}/reports/enrollment` | Admin, management, or independent educator | Returns aggregate active learner placement by session/section, unassigned learner count, and enrollments in published courses. It is tenant-scoped and excludes personal identifiers. |
| `GET /api/v1/organizations/{organization}/reports/workload` | Admin, management, or independent educator | Returns active teacher section assignments, per-teacher distinct active learner reach, and active weekly timetable slot counts/hours for sessions active on the organization's local date. Teacher and learner roles cannot read organization-wide totals. |
| `GET /api/v1/organizations/{organization}/reports/finance?from={date}&to={date}` | Admin, management, or independent educator | Returns organization-wide INR fee record counts, issued/received/outstanding/overdue totals, all-time expenses and net cash flow, plus date-filtered receipt/outflow counts and totals (default: last 30 days, maximum: 366 days). This report aggregates staff-entered records; bank statement matching is a separate manual workflow and does not connect to a payment provider. |
| `GET /api/v1/organizations/{organization}/exams` | Admin, management, independent educator, or teacher | Lists up to 100 tenant exams with papers. Teachers see exams and papers only for matching teaching assignments. |
| `POST /api/v1/organizations/{organization}/exams` | Admin, management, or independent educator | Creates a draft examination inside an active academic session date window. |
| `POST /api/v1/organizations/{organization}/exams/{exam}/papers` | Admin, management, or independent educator | Schedules a unique section/subject paper with exam date and maximum marks. Optional named paper sections are accepted when their maximum marks add up to the paper maximum. |
| `GET /api/v1/organizations/{organization}/exam-papers/{paper}/results` | Admin, management, independent educator, or assigned teacher | Lists the active student roster, saved total marks and section scores for the paper. Teachers are limited to their assigned session, section and subject. |
| `PUT /api/v1/organizations/{organization}/exam-papers/{paper}/results` | Admin, management, independent educator, or assigned teacher | Saves grades, absences or excused outcomes for active students; score caps, roster placement and published-result lock are enforced. For sectional papers, every graded student needs a score for each section and the scores must sum to the total. |
| `POST /api/v1/organizations/{organization}/exams/{exam}/publish` | Admin, management, or independent educator | Publishes only after each active roster student has a result or absence for every paper. Published results become read-only. |
| `GET /api/v1/organizations/{organization}/reports/exams?session_id={id}` | Admin, management, independent educator, or teacher | Summarizes published exam results by exam, section and subject with graded/absent/excused counts and average marks; sectional papers also include per-part averages and graded counts. Teachers see only papers in their exact assigned session/section/subject scope. Student identities are omitted. |
| `GET /api/v1/organizations/{organization}/reports/exams/sections?session_id={id}` | Admin, management, independent educator, or teacher | Aggregates each published exam and academic class section across its papers, with paper/subject/learner/result counts and the average of graded result percentages after normalizing each paper by its maximum marks. Teachers see only their assigned session/section/subject results. Student identities are omitted. |
| `GET /api/v1/organizations/{organization}/my/student/results`, `GET .../my/children/{student}/results` | Student, or parent with an explicit child link | Includes only published institution exam results for the authenticated student or linked active child, alongside quiz and assignment results. |
| `GET /api/v1/organizations/{organization}/bank-statements` | Admin, management, or independent educator | Lists up to 30 tenant-owned imported statement batches and their matched/unmatched transaction lines. |
| `POST /api/v1/organizations/{organization}/bank-statements` | Admin, management, or independent educator | Imports 1–500 CSV-decoded lines with account label, period, opening/closing balances, date, description, credit/debit, amount and optional reference. The balance equation must reconcile; duplicate statement contents are rejected using a tenant-scoped fingerprint; no bank credentials or raw uploaded file are stored. |
| `GET /api/v1/organizations/{organization}/bank-statement-lines/{line}/candidates` | Admin, management, or independent educator | Finds up to 50 unmatched same-tenant fee receipts or paid expenses with exact amount and dates within seven days, according to line direction. |
| `POST /api/v1/organizations/{organization}/bank-statement-lines/{line}/match` | Admin, management, or independent educator | Links the line to one same-tenant fee receipt or expense. Direction, exact amount, seven-day date window and one-to-one matching are enforced. |
| `DELETE /api/v1/organizations/{organization}/bank-statement-lines/{line}/match` | Admin, management, or independent educator | Reverses a match while retaining the imported statement line. |
| `GET/POST /api/v1/organizations/{organization}/expenses` | Admin, management, or independent educator | Lists tenant-scoped recorded expenses and records a paid operating expense with category, amount, organization-local date, method and optional reference/notes. Future dates are rejected. |
| `GET/POST /api/v1/organizations/{organization}/announcements` | Admin, management, or independent educator | Lists recent notices or sends a bounded title/body to the selected active audience in-app; verified members who separately opted in can receive queued email if the environment enables it. |
| `GET /api/v1/organizations/{organization}/reports/assessments` | Admin, management, independent educator, or teacher | Summarizes published quizzes and assignments, attempt/submission/review counts, learner participation, and weighted score averages. Teachers are limited to their published courses. Student identity is omitted. |
| `PUT /api/v1/organizations/{organization}/courses/{course}/lessons/{lesson}/progress` | Same as above | Sets or clears completion for a published lesson in the enrolled course; each student can only change their own progress. |
| `GET /api/v1/organizations/{organization}/fees` | Verified admin, management, independent educator, linked student, or linked parent | Returns organization fees to authorized staff; students see only their linked profile and parents only explicitly linked active children. Supports staff `student_id` and status filters. |
| `POST /api/v1/organizations/{organization}/fees` | Admin, management, or independent educator | Creates a manual INR receivable for one active organization student, with optional category and due date/session. A category must be active and belong to the same organization. Does not charge money. |
| `POST /api/v1/organizations/{organization}/fees/{fee}/payments` | Admin, management, or independent educator | Requires a 16–128 character `Idempotency-Key` header. Records money already received by staff with method/reference and receiver audit fields. Identical retries for the same organization, fee and payload return the existing fee result without adding a receipt or sending another notice. Reusing the key for different fee/payment details returns 409. Overpayment is rejected transactionally. This is not a payment gateway. |
| `GET /api/v1/organizations/{organization}/meetings` | Verified organization managers, assigned teachers, enrolled students, or linked parents | Lists management meetings for managers; class meetings are limited to the caller's assigned teaching sections/courses, enrolled student sections/courses, or explicitly linked children's sections/courses. |
| `GET /api/v1/organizations/{organization}/notifications` | Verified active organization member | Lists only notifications addressed to the caller and tagged for the selected organization; entries sort newest-first with a stable creation-time/ID order so read receipts do not shift pagination boundaries, and `per_page` is bounded to 1–100. |
| `POST /api/v1/organizations/{organization}/notifications/{notification}/read` | Verified active organization member and notification recipient | Marks one of the caller's notifications for that organization as read; other users' and organizations' IDs return not found. |
| `GET /api/v1/organizations/{organization}/email-deliveries` | Verified active organization member | Lists only the caller's queued/sent/failed/cancelled email delivery status for this organization; response omits message bodies and provider error detail. |
| `GET/PATCH /api/v1/me/notification-preferences` | Sanctum authenticated account | Reads or updates in-app preferences (enabled by default) and separate email opt-ins for announcement, meeting, and fee categories (disabled by default). Email opt-in is rejected while `WORKSPACE_EMAIL_NOTIFICATIONS` is off. Email sends only to verified accounts; push preferences are not offered. |
| `GET /api/v1/organizations/{organization}/dashboard/summary` | Admin, management, independent educator, active assigned teacher, linked student, or linked parent | Admin/management receive active roster counts, timetable slots for today, and today's attendance. Independent educators receive published course, unique learner, ungraded submission, and upcoming live class counts. Teachers receive their active assigned class/learner counts, ungraded submissions for their own published courses, and weekly assigned timetable slots. Students receive their own active course count, lessons completed over the last seven local calendar days, unsubmitted published assignment count, and 30-day attendance. Parents receive linked active child count, child-only pending assignments and attendance, and upcoming meetings only for linked sections/courses. Date windows use the organization timezone; no attendance marks returns a null rate. |
| `GET /api/v1/organizations/{organization}/dashboard/activity` | Admin, management, independent educator, linked teacher, student, or parent | Returns seven organization-local day totals of published lesson completions and assignment submissions. Teachers are limited to their published courses; learners only see their own activity; parents see activity for explicitly linked active children. It returns aggregate counts without learner identifiers. |
| `POST /api/v1/organizations/{organization}/meetings` | Admin, management, independent educator; teachers with a matching teaching assignment | Schedules a one-time management or class meeting with an HTTPS provider URL. Start/end times, organization-owned course/section/session, and overlapping class meetings are validated. Provider room creation is not connected. |
| `PATCH /api/v1/organizations/{organization}/meetings/{meeting}` | Admin, management, independent educator, or the teacher who created the class meeting | Cancels a meeting without deleting its audit record. Students and parents are read-only. |
| `GET/POST /api/v1/organizations/{organization}/meetings/{meeting}/recordings` | Meeting viewers; recording creation by managers or the teacher who created that class meeting | Lists visible recordings; students and linked parents receive published recordings only. Staff can add a private MP4, MOV, or WebM file up to 50 MB, or an external HTTPS link. Creation requires staff attestation that participants were notified and applicable consent was obtained. |
| `PATCH /api/v1/organizations/{organization}/meetings/{meeting}/recordings/{recording}` | Managers or the teacher who created the class meeting | Publishes, unpublishes, or withdraws a recording. Withdrawn recordings cannot be republished; underlying private files are retained pending a defined retention policy. |
| `GET /api/v1/organizations/{organization}/meetings/{meeting}/recordings/{recording}/download` | Authorized meeting viewer | Streams an uploaded file from private storage after rechecking current meeting access and publication status. External links open at their HTTPS destination; the API does not fetch them. |
| `POST /api/v1/organizations/{organization}/meetings/{meeting}/recordings/{recording}/download-link` | Authorized meeting viewer | Issues a two-minute relative signed URL for an uploaded published recording after checking meeting access. The signed route rechecks publication and streams the private file without embedding an account token; intended for native clients that cannot send Sanctum cookies to the device browser. |
| `GET /api/v1/meeting-recordings/{organization}/{meeting}/{recording}/download` | Two-minute relative signed URL from the authenticated download-link endpoint | Streams the currently published private recording; signature, path, expiry, publication and stored-file existence are checked. |
| `POST /api/v1/enquiries` | Public, limited to 6 requests per minute per client | Validates contact details and explicit consent, silently drops honeypot submissions, and persists accepted enquiries. Sends a raw notification only when `ENQUIRY_RECIPIENT` and a real mail transport are configured; response reports whether notification was sent. |
| `GET /api/v1/enquiries?status={status}&q={search}` | Authenticated, verified user whose email is explicitly listed in `ENQUIRY_ADMIN_EMAILS` | Returns paginated contact records, optionally filtered by status and search text; this is a platform-wide operator capability and is not granted by organization membership. |
| `GET /api/v1/platform/overview` | Verified user whose email is explicitly listed in `PLATFORM_ADMIN_EMAILS` | Returns aggregate organization/user/educator/enquiry counts and recently created organization metadata; tenant membership does not grant platform access. |
| `GET /api/v1/platform/organizations?q={search}&status={status}` | Same verified platform operator allowlist | Returns paginated organization metadata with active membership/student/teacher totals; read-only, searchable by name or slug, and filterable by active/suspended status. |
| `PATCH /api/v1/platform/organizations/{id}` | Same verified platform operator allowlist | Changes organization status to `active` or `suspended`; requires a reason (8–500 characters) and transactionally records actor, organization snapshot, before/after status, and reason. Suspension removes the organization from member selection and access; reactivation restores access. |
| `GET /api/v1/platform/audit-events?organization_id={id}&per_page={n}` | Same verified platform operator allowlist | Returns paginated organization and platform-account status, identity and invitation audit events, including actor, reason and before/after values; no credentials or invitation tokens are returned. |
| `GET /api/v1/platform/users?q={search}&role={role}&email_verified={boolean}&status={active|suspended}` | Same verified platform operator allowlist | Returns a paginated account directory with email-verification, account status and active-organization counts; searchable by account name/email and filterable by active organization role, email-verification state or global account status. Passwords and tokens are excluded. |
| `PATCH /api/v1/platform/users/{id}` | Same verified platform operator allowlist | Suspends or reactivates an account with an 8–500 character reason; actor and before/after account status are audited. Suspension blocks new sign-in and all authenticated API routes. Self-suspension and changes to allowlisted operator accounts are rejected. |
| `PATCH /api/v1/platform/users/{id}/profile` | Same verified platform operator allowlist | Updates an ordinary account's name/email with an 8–500 character audit reason. Allowlisted operator accounts are protected. Changing email clears verification and sends a verification notification to the new address; local mode also returns its signed URL. Passwords cannot be set by this endpoint. |
| `GET /api/v1/platform/invitations?status={pending|expired|accepted|revoked}&organization_id={id}&q={search}&per_page={n}` | Same verified platform operator allowlist | Lists staff invitations across organizations with organization, inviter, state and dates; filters by organization, email/organization search and state. Invitation secrets are never returned. |
| `POST /api/v1/platform/invitations` | Same verified platform operator allowlist | Sends an audited, seven-day organization invitation for an active organization and an Admin, Management, Teacher or Independent Educator role. Requires an 8–500 character reason; active/suspended existing memberships and suspended platform accounts are rejected. The recipient sets their own password and activates the role by accepting the existing invitation flow. Under `APP_ENV=local`, the response includes a development invitation URL; production exposes no token in the response. |
| `DELETE /api/v1/platform/invitations/{id}` | Same verified platform operator allowlist | Revokes an unaccepted staff invitation with an 8–500 character reason, retains the invitation record, and writes a platform audit event. Revoked tokens cannot be accepted; accepted invitations cannot be revoked. |
| `POST /api/v1/platform/invitations/{id}/resend` | Same verified platform operator allowlist | Renews and emails an unaccepted staff invitation for an active organization, rotates the token, and sets a fresh seven-day expiry. Requires an 8–500 character reason and writes an audit event without the token. Accepted/revoked invitations cannot be resent. Under `APP_ENV=local`, the response includes a development invitation URL. |
| `PATCH /api/v1/enquiries/{id}` | Same allowlisted platform operator | Sets status to `new`, `in_progress`, `resolved`, or `archived`; records reviewer and review timestamp. |
| `POST /api/v1/enquiries/{id}/reply` | Same allowlisted platform operator | Validates and sends a plain-text reply to the enquiry email using the configured mail transport. On success, records responder/time and moves a new enquiry to in progress; on transport failure, returns 503 and records no reply. Reply text is not retained. |
| `POST /api/v1/auth/register` | Public, throttled | Validates name, email, 12+ character letter-and-number password, organization name/type; creates user, organization, and initial active membership in one transaction; sends verification. Duplicate-email response is intentionally generic. Under `APP_ENV=local`, the response also contains a short-lived signed `verification_url` for local browser use. |
| `POST /api/v1/auth/login` | Public, throttled | Requires verified account and valid credentials. Without `device_name`, creates a first-party browser session. With `device_name`, issues a 30-day Sanctum bearer token. |
| `POST /api/v1/auth/logout` | Sanctum authenticated | Deletes the current bearer token or invalidates the browser session. |
| `POST /api/v1/auth/email/verification-notification` | Public, throttled | Sends a verification message when an unverified account exists; response does not reveal account existence. Under `APP_ENV=local`, an existing unverified account also receives a short-lived signed `verification_url`; other environments omit it. |
| `GET /api/v1/auth/verify-email/{id}/{hash}` | Signed, throttled | Validates the expiring signed URL and marks the matching user email as verified. |
| `POST /api/v1/auth/forgot-password` | Public, throttled | Sends password reset instructions when an account exists; response message is generic. Link is built for `FRONTEND_URL/reset-password`. Only under `APP_ENV=local`, the response also contains a clickable `reset_url` for an eligible account; other environments do not return reset tokens. A successful reset revokes the matching current browser session and all Sanctum tokens for that account. |
| `POST /api/v1/auth/reset-password` | Public, throttled | Accepts email, reset token, and confirmed password; consumes the reset token and revokes existing API tokens. If the current browser session belongs to the reset account, the endpoint also invalidates that session; an unrelated signed-in account's session is preserved. |
| `GET /api/v1/me` | Sanctum authenticated | Returns current user's ID, name, email, verification timestamp and whether their email is allowlisted for platform operations; omits credentials. |
| `PATCH /api/v1/me/profile` | Sanctum authenticated, active account; throttled and requires the current password | Updates the signed-in user's name/email and optionally a confirmed password. Email is normalized and unique; changing it clears verification and sends a new verification notification. A password change revokes the user's other Sanctum API tokens while retaining the active token. Local development includes a short-lived signed verification URL. Platform operator emails cannot be changed through this endpoint or claimed by another account. |
| `GET /api/v1/organizations` | Sanctum authenticated and verified | Returns paginated active organization memberships for the current user only, including role and basic organization details, plus `preferred_organization_id` when that organization is still active and accessible. `per_page` is bounded to 1–100. |
| `PATCH /api/v1/me/organization` | Sanctum authenticated and verified | Saves the user's preferred organization only after checking that the user has an active membership and the organization is active; returns the selected membership. |
| `GET /api/v1/organizations/{organization}` | Sanctum authenticated and verified | Returns organization details only to an active member; other users receive 404. |
| `PATCH /api/v1/organizations/{organization}/settings` | Verified admin or independent educator in the active organization | Updates the organization name and/or IANA timezone. Empty updates and invalid timezones are rejected; management and other roles are denied. |
| `GET /api/v1/organizations/{organization}/invitations` | Admin, management, or independent educator in an active verified membership | Lists tenant invitations with pending, accepted, or expired state. |
| `POST /api/v1/organizations/{organization}/invitations` | Same roles; management invitations are admin-only | Sends a seven-day invitation to a permitted role. Student invites require an active matching student roster email; parent invites require 1–20 active tenant student IDs. Raw tokens are never returned by the API; invitations can be revoked before acceptance. |
| `GET /api/v1/organizations/{organization}/parent-accounts` | Admin, management, or independent educator | Lists active, verified parent accounts in this organization for linking to student records. |
| `GET/POST /api/v1/organizations/{organization}/students/{student}/guardians` | Admin, management, or independent educator | Lists a student's explicit guardian links or links an active, verified parent membership. Supports relationship type and primary-contact status; selecting a new primary clears the previous primary link. |
| `DELETE /api/v1/organizations/{organization}/students/{student}/guardians/{guardian}` | Admin, management, or independent educator | Removes only the selected organization/student/guardian link. Guardian users must be active parent members of the same organization before linking. |
| `DELETE /api/v1/organizations/{organization}/invitations/{record}` | Same roles | Revokes a pending invitation. Accepted invitations cannot be revoked through this route. |
| `GET /api/v1/auth/invitations/{token}` | Public, throttled | Returns invitation email, role, organization name, and expiry for a valid one-time token. |
| `POST /api/v1/auth/invitations/register` | Public, throttled | New invitees create an account and accept; existing invitees confirm with their account password. The invitation proves email access and activates a membership. Teacher and student acceptance link the matching roster profile; parent acceptance links only the student profiles selected on the invitation. |
| `POST /api/v1/organizations/{organization}/invitations/{token}/accept` | Authenticated, verified invitee whose email matches the invitation | Accepts an invitation for an existing signed-in account. |
| `GET/POST /api/v1/organizations/{organization}/academic-sessions` | Verified active organization member; writes by admin, management, or independent educator | Lists or creates tenant-scoped sessions. Dates must be ordered; session names are unique per organization; current-session switching is transactional. |
